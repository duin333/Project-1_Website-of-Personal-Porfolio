# Ghibli piano player

Piano covers selected by the portfolio owner, embedded using the visible YouTube IFrame player. No audio is downloaded, extracted or re-hosted.

Composer: Joe Hisaishi. Performer uploads:
- Merry-Go-Round of Life — Animenz Piano Sheets: https://www.youtube.com/watch?v=lB4PRX737-0
- Path of the Wind — PianoDeuss: https://www.youtube.com/watch?v=GlFGmFyJuG0

API reference: https://developers.google.com/youtube/iframe_api_reference

The API loads only after a playback action. The player stays visible while listening. Closing it destroys the player and stops playback; reloads never autoplay. Native YouTube controls and a direct watch link remain available. Track and volume preferences are stored locally. Playback depends on network access, browser autoplay rules and the uploader's current embedding permissions. Errors offer another track or the original watch page.
